# README Introduction Refresh Design

## Goal

Make the English README easier to scan while preserving Matrix's purpose, major capabilities, supported desktop platforms, and authorized-use boundary.

## Content structure

1. A concise product description identifying Matrix as a Flutter desktop application for authorized webshell management and security testing.
2. Four capability groups: webshell operations, payload management, security testing, and intranet tunneling.
3. The existing Flutter quick-start command, with the desktop-platform scope note.
4. A brief authorization-only disclaimer.

## Scope and exclusions

- Remove exhaustive connector, payload, and vulnerability/CVE inventories from the README landing page.
- Do not change application code, build configuration, or security functionality.
- Keep wording factual and avoid claiming unsupported platforms or capabilities.

## Verification

Review the rendered Markdown for a clear heading hierarchy, concise feature descriptions, a working quick-start block, and a visible authorization disclaimer.
